Conventions (décidées par le propriétaire le 25 octobre 2026)
  1. PER couvre le nom complet : prénom, nom, patronyme, origine, épithète, numéral. [Lorenzo il Magnifico], [Henry the Eighth], [Gabriel Byel ex Spira].
  2. Titres, formules et parenté hors du PER : don, messer, Sir, duca, Herr, D., « la mère de ». don [Fadrique], Sir [Philip Sidney], la mère de [Luther]. Même pour les noms de fiction : Don [Quijote]. Les titres de saint restent hors du PER : San [Giovanni].
  3. Lieu dans un nom de personne : pas un lieu. Tout le nom est PER. [Lunardo da Dresano|PER], [Friderich von Zimbern|PER].
  4. Lieu dans un titre : lieu, et pas de personne. Le titre reste dehors. Duca di [Milano|LOC], Roy de [France|LOC], le Duca di [Calabria|LOC] est arrivé.
  5. Souverain suivi d'un lieu : le souverain est PER, le lieu est LOC. [Felipe II|PER] de [España|LOC].
  6. Peuples, gentilés, adjectifs de lieu, langues : rien. Turca, Polonicis, les Français, French Wines. Exception : adjectif latin en -ensis = LOC.
  7. Dieu : rien. Christ, saints, diable, figures bibliques, dieux antiques : PER. Personnifications (Amor, Fortuna) : rien. Astres : rien.
  8. Bâtiments et lieux génériques : rien (l'église, la piazza), sauf s'ils sont nommés ([San Marco|LOC]).
  9. Point final toujours hors du nom, y compris le point d'abréviation : [Lond]., [Io]., [Panor]., [Clemens V].
  10. Lieux de gold v2 : verrouillés. Ce sont les décisions déjà prises ; on ne les modifie pas ici.
